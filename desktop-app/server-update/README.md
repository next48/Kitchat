# Обновление сервера для KitChat 1.5.6

Этот пакет ещё не установлен на oliverkitchen.ru. Новый IPA не заменяет PHP на сервере.

Сначала сохраните копии текущих `api/direct_messages.php` и `api/call_signal.php` с хостинга. Сравните их с этим пакетом: если на хостинге есть более новые изменения, перенесите добавленные обработчики, сохранив эти изменения. Затем загрузите эти два файла в каталог `api` сайта.

Пакет использует существующие `bd/database.php`, `bd/desktop_session.php`, `bd/onesignal.php` и таблицы пользователей/друзей. Для личных сообщений добавлены `edit` и `delete`: менять и удалять сообщение может только отправитель. Для звонков добавлена авторизация с токеном приложения, проверка дружбы и определение имени звонящего сервером.

После установки проверьте двумя тестовыми аккаунтами: отправку сообщения, изменение текста, удаление у обоих участников, невозможность изменения чужого сообщения; исходящий звонок, ответ, отказ, отмену, микрофон и завершение с обеих сторон.

CallKit включён в клиент iOS для системного интерфейса активного звонка. Это не доставка вызовов при закрытом приложении. PushKit/APNs в этом пакете не настроены; бесплатная подпись iLoader/SideStore не предоставляет нужное push-разрешение. Dynamic Island и звук при сворачивании требуют проверки на физическом iPhone.
