# Kitchat 1.5.4

- Новая тема «Ярко-розовый»: светлый нежно-розовый интерфейс, белые карточки с мягкими тенями и падающие лепестки.
- Версия для macOS: родные кнопки окна, возврат окна по клику на иконку в Dock, сборка для Apple Silicon и Intel.
- Вход и настройки надёжно сохраняются между запусками.
- Ваша камера отражается только у вас на экране; собеседники видят её без зеркалирования.
